# Contributor Covenant Code of Conduct

This project adopts the Contributor Covenant version 2.1. The full text is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

## Reporting

To report a violation, email the maintainer at `mtalha.dev@protonmail.com`. Reports are confidential and will be acknowledged within five business days.

## Scope

This Code of Conduct applies within all project spaces and in public spaces when an individual is representing the project.
